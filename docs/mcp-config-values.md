# MCP 配置值：展示、编辑原值与运行值

配置值有三个不同契约，不能彼此替代：

- **展示值**：列表、详情、搜索只读取当前来源，文本只能是可渲染文本；数字和布尔保留实际字面类型。序列化的 loader `__jsExpr` 节点与内部 `!!js` 字符串会标成表达式，不在展示期执行。
- **编辑原值**：未修改字段提交 `preserveFields` 引用，原值由 Host 在当前配置锁内取得，不从浏览器接受原节点。已有敏感叶的保留标记也只绑定当前服务器、字段和原 key。表达式、YAML 标签与注释由原节点保留；未指定的默认字段不会因为打开保存一次而添加。
- **运行值**：只在现有授权的“查看原值”通路使用宿主求值器；运行结果不会自动成为新配置。

## 使用行为

表达式字段默认保留。文本输入在保留时禁用，数值/布尔/容器不会显示虚构的实际默认量。取消保留后必须真正提供替换值；数值需填写、布尔需明确选择 true/false。只有取消保留、没有新输入，保存会明确报错。

完整 env/headers/args 表达式显示为“表达式，原值已隐藏”，不伪造 map key 或参数内容。未知结构值仍可在面板看到诊断，但不可被 JSON/stringify 成合法命令；当前面板不能安全编辑时，会在概览显示原因，而不只依赖禁用按钮的悬浮标题。

原始 MCP 配置文件里不要写 `configValues` 或 `preserveFields`：它们是面板的 read model/更新请求元数据，不是 MCP 客户端配置。

## 保存与准入

新建、导入、修改的新值继续走原受限环境变量表达式准入，不因支持旧表达式保留而放开任意 JS。更新先规范并锁定目标名称、传输及 URL 别名；目标不能被数组/对象 coercion 改投另一条目，保留与新值混用必须拒绝。

全局只编辑本 Web profile 的原条目；项目在当前已注册工作区内查原服务器。外部 bundle/Agent 条目只读。全局不支持改名；项目原有显式改名仅在不携带原值/敏感引用时保留。

省略 disabled/defer 是保留源状态，不是重新启用。需要启停时使用对应操作或显式布尔值；不能把页面看到的 effective enabled 写回覆盖原来的动态 disabled 表达式。连接变更判据在表达式/不透明生命周期源变成布尔时按源变化对齐，不能把“表达式 → false”当成无变化。

项目 JSON 保持已有环境变量模板协议；全局已有任意 `!!js` 节点可在未修改时保留，不代表可把同样内容作为新项目/导入值执行。
