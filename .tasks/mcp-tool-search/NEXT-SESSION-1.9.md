## 1. 已定案并落地（**不要再翻**，除非拿出反证）

完整推理在 `docs/mcp-tool-search-design.md` **§12.11**（唯一真源）。要点：

1. **目录形态** = 按 MCP 服务器分组 + **裸名**（剥掉 `mcp__<server>__`）。456 工具 / 7 台实测：
   旧口径 300 行全名 = 12,896 字符且隐藏 142 个；新口径列出全部 456 个，整段 11,690（-9.4%）。
2. **预算 = 字符，不是行**：`maxCatalogChars` **缺省不设 = 不截断**（2026-10-26 同日修订；
   面板上是一个**默认关闭**的开关，打开时预填 12,500 作建议起点），设了才**只算名字行**
   （标题/intro/组头 ≈700 字符是"地图骨架"另付）。`maxCatalogLines` 已删除，写进配置会显式报错并给换算。
3. **分配粒度 = 整行**，装不下就少一行（I6）；超预算时按服务器**注水**，任何服务器不会整台消失。
4. **`select:` 支持裸名**：唯一命中直返**全名**，多命中全返，缺失仍 `found:false`。
5. **截断可观测**：`truncated > 0` 时 `warnOnce`（键带 revision），日志带当前预算值。
6. **归属/切分不做字符串解析**：`owner` 来自 `view.ownerOf`（`uniqueOwner` 前缀唯一命中），
   切分点是 `'mcp__'+owner+'__'` 的**长度**且先 `startsWith` 验证；归不上就保留全名。
   禁止 `split('__')`。`serverName` 受 `/^[A-Za-z0-9_-]{1,32}$/` ⇒ 前缀最长 39 < 截断保留区 51，
   **64 字符截断永远切不坏前缀**。
7. **明确不做**：组内 LCP 剥公共前缀（会剥语义前缀 + 字节不稳定 + 真实数据收益 0）；
   剥 `serverName_` 重复段（精确匹配抓不住变体如 `deepwiki_fetch`，全剥也只省 <3%）。

## 2. 待议（本次新会话的正题）

### Q3 中文查询匹配

**缺口精确定义**（不是"中文都不行"）：

| 场景 | 现状 |
|---|---|
| 中文查询 × 中文描述 | ✅ 已支持（CJK 二元分词，`lib/tool-search-index.js`） |
| 英文查询 × 英文名/描述 | ✅ BM25 最强项 |
| **中文查询 × 英文描述** | ❌ 恒 0 分 —— **唯一真缺口** |
| 中文查询 × 中文描述但措辞差一字（`截个屏` vs `截图`） | ❌ 二元组不重叠 → 0 分（词面天花板） |

**已有一条真机旁证**（2026-10-26）：把新目录喂给 DeepSeek，中文提问"帮我把当前页面截个图"
→ 模型自动翻成英文查询 `take screenshot of current page` 并正确调用 `tool_search`。
即 **L2（模型自己翻译）在常规 case 下够用**。

候选手段：L1 从用户目录自学习共现映射（零人工、R1/R5 合规）→ L2 模型自己翻译（提示词已有半句）→
~~L3 手写中英词表~~（**R1 否决，不要再提**）。

**要定它，缺的是数据**：一个离线夹具，20–30 条中文能力描述 × 真实工具集（serena 28 /
chrome-devtools 32 / jshook 360），三组对照：纯 BM25 / +L1 共现 / +手写表（只作上限参考）。
指标 recall@10。判据：BM25 ≥85–90% ⇒ 不做；<70% ⇒ 先补 L1/L2 再测；仍不行才谈向量。

### Q4 embedding

- **形态**：BYO 端点（OpenAI 兼容 `/v1/embeddings`），默认 `off`，**插件不带模型**（不塞 600MB）。
  用户能选的是**端点**，不是算法（BM25 / embedding 的算法选择不暴露）。
- **必须**：RRF 融合（不是二选一）；缓存键 `sha256(serverName + toolName + schemaText)` 落盘、
  跨会话复用、懒建；失败/超时 ⇒ 本次退回纯 BM25 + `warnOnce`，**不许静默成"没结果"**。
- **前置**：以"带 Q3 结论的 BM25"为基线测边际收益，否则等于自欺。
- **卡点**：宿主**没有** embedding 服务（`packages/` 全仓只有两处无关的 "embedding" 字样）。

### Q1 下一版宿主迁移（有时限，但**作者要求现在不动**：rc.4 还没发）

- 事实：rc.3 之后 `system-prompt/assemble` 不再携带 `tools`（改为 `PromptPresentation`），
  声明权归 `systemPrompt.tools()` provider；新增 `register(def, { when })` 每步准入。
  所以现在的装配期遮罩在下一版**会静默失效**（目录/引导/守卫还在，但工具不再被藏）。
- 方案：项目族（本插件自己注册）用 `when`；全局族（宿主 mcp-client 注册）用 `restrict({deny})`。
- **唯一取舍**：两者都让工具在 `executable()` 里消失 ⇒ 失去 guard 的"带指引拒绝"（退化成
  `UNKNOWN_TOOL`）。要保指引就只能继续做装配期遮罩。
- 卡点：装机是 rc.3，`when` 在 rc.3 不存在，改完**没处验证**。触发条件：rc.4 发布。
